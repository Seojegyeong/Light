개인정보처리방침

Privacy Policy · light Chrome Extension · 최종 수정: 2026-07-31

1. 수집하는 정보

light은 다음 정보만 수집합니다.

  • 사용자 설정값 (light_settings): 하이라이트 활성화 여부, 카테고리 필터, 색상 선택

2. 정보 이용 목적

수집된 설정값은 Chrome 기기 간 설정 동기화 목적으로만 사용됩니다.

3. 정보 저장 방식

설정값은 Chrome의 chrome.storage.sync API를 통해 저장되며, 구글 계정에 연동된 Chrome 브라우저 간에만 동기화됩니다. 개발자 서버 또는 외부 서버로 전송되지 않습니다.

4. 제3자 공유

light은 수집된 어떠한 정보도 제3자에게 공유하거나 판매하지 않습니다.

5. 데이터 삭제

Chrome 확장 프로그램을 제거하면 저장된 모든 설정값이 삭제됩니다. Chrome 설정에서 사이트 데이터를 직접 삭제할 수도 있습니다.
